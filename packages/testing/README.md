# @gehu-js/testing

Framework-agnostic test helpers for Gehu stores.

```sh
bun add -d @gehu-js/testing @gehu-js/core
```

Exports `createTestStore`, `createLinkedTestStore`, `captureActions`, `capturePatches`, `flushEffects`, `flushResources`, `mockResource`, and `mockMutation`.

Full docs: https://github.com/knoxpo/gehu#readme
